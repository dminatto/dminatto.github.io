## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm / yarn / pnpm

### Installation

```bash
# Clone the repo
git clone https://github.com/daniele-minatto/character-portfolio.git
cd character-portfolio

# Install dependencies
npm install

# Run dev server
npm run dev

Open http://localhost:3000 to view the character sheet 🧙‍♀️

```

### Build for Production

```bash
npm run build
npm start
```

### Deploy on Vercel

```bash
vercel --prod
```

Or connect your GitHub repo at vercel.com/new for auto-deploys.
